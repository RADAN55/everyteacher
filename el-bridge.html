The four lanes, in one page

Every lane keeps the same grade-level content objective. What changes is the language students use to get there. The lanes map to ELPA21 proficiency levels, which is how Mississippi reports EL progress.

Mississippi frameworks and tests this tool references

  • MS CCRS for English Language Arts — RL / RI / W / SL / L / RST / WHST codes (e.g., RI.8.2). English II is assessed on the 9–10 band.
  • MS CCRS for Mathematics — K–8 by grade and domain (e.g., 6.RP.3); high school by conceptual category. Algebra I draws on N-Q, A-SSE, A-CED, A-REI, F-IF, F-BF, F-LE, and S-ID.
  • MS CCRS for Science (2018) — Domain.Grade.Standard.Objective (e.g., L.5.3B.1); Biology I is BIO.1A–BIO.6.
  • MAAP — Mississippi Academic Assessment Program: grades 3–8 ELA and math, grades 5 and 8 science, and the Algebra I, Biology I, English II, and U.S. History end-of-course tests. Item types include multiple choice, multi-select, evidence-based selected response, technology-enhanced, and constructed response/writing.
  • MS English Language Proficiency Standards and ELPA21 — the proficiency levels the lanes are built on.
  • MS Testing Accommodations Manual (MTAM) — the allowable EL accommodations for state tests (for example, extended time, small group, bilingual word-to-word dictionary, read-aloud of directions, and read-aloud of test items where the test permits). Classroom supports here are broader than MTAM; only MTAM-listed accommodations carry to MAAP, and translated items are not an allowable MAAP accommodation.

Confirm standard wording and accommodation rules against the current MDE documents before placing them in a formal plan.

What “linguistically accessible” means for an item

  • Same standard, same cognitive demand, same key. Only the language load changes.
  • Shorter sentences, active voice, familiar words outside the tested vocabulary, no idioms.
  • Tested academic terms stay; everything around them simplifies.
  • Visual support when the construct allows (a diagram, a table, bolded quantities).
  • Consistent wording across stem and options; one question per sentence.

Writing a language objective

  • Pattern: Students will [function] [content] using [form] with [support].
  • Example: Students will explain how a food web changes when a species is removed, using “if…then…because” sentences with a word bank.
