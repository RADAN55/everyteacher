Where this comes from

Thirteen public feeds, read every morning at 4:40 Central by the hub's own script, kept thirty days, sorted by whether they are about English learners. Headlines and first lines are the publishers'; links go to the source. The morning picks are drafted by Richard's scheduled assistant and reviewed when he reads them — the take is the hub's, the reporting is theirs.

How it updates. A script in the hub's own repository (tools/fetch-feed.py, run by a GitHub Action at 4:40 a.m. Central) reads the feeds listed in tools/feeds.txt and writes daily/feed.json; the page reads that file when you open it. The three picks come from a separate morning run that writes daily/picks.json. To add a source, add one line to feeds.txt. Nothing is stored about readers.
