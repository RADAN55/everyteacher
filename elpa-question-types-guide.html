Five steps that work on every question

Most wrong answers come from skipping step 1. Name the question type first, and you know what kind of answer to look for.

  1. Name itRead the question stem. Which of the 18 types is it?
  2. Mark itCircle the question word and the key word: who, why, mainly, first, closest.
  3. Find itGo back to the text, picture or speaker. Put a finger on the evidence.
  4. Predict itSay your own answer before you read the choices.
  5. Cross outRemove choices that are too small, not in the text, opposite, or true but off-topic.

Four ways wrong answers are built

Test writers make wrong choices on purpose. Learn the four shapes and they stop looking attractive.

Too small

True, but only one detail. It is not the whole idea.

Not in the text

Sounds reasonable, but the passage never says it. Look for proof.

The opposite

Uses the right words but reverses the meaning. Check small words like not, only, never.

True but off-topic

A fact from the passage that does not answer this question.

For the teacher: how to use this guide

In a 90-minute block

Teach three question types a day. For each, project the example, have students name the type and predict the answer before they see the choices, then tap to check and read the reason for the choice they picked. The five steps on this page are the routine; say them aloud every time until students say them without you.

Reading and listening

The same types appear in reading and in listening. Use the Read it aloud button (it uses the device's own voice) to run any example as a listening item: students close their eyes, hear the passage and question once, then answer. For a fuller listening practice set, use the Listening and Speaking Studio.

Differentiation

Newcomer and Emerging: start with Identify a Picture, Key Details, Sequence and Complete a Sentence; allow the stems to be read aloud and answers to be spoken. Progressing: add Cause and Effect, Vocabulary in Context, Comparison and Reference Words, and have students write a one-sentence reason for each answer. Challenge: Inference, Text Evidence, Author's Purpose, Paragraph Purpose and Summarize; have students write their own wrong answers in the four shapes above.

Around the guide

Use sentence frames to let students explain their choice ("I chose B because the passage says ..."), and Write About It for the writing side of the test. Progress on this page stays in the student's browser.
